# Changelog

## 3.0.0 - 2026-07-10

### Changed

- Made plain writing the neutral baseline.
- Changed rewrite mode to return clean prose first.
- Narrowed false-agency, rhythm, adverb, and punctuation rules so they do not damage precise writing.
- Removed unsupported frequency claims, authorship language, automatic score thresholds, and examples that invented evidence.
- Rebuilt the public site around the v3 workflow and content.

### Added

- AI-role, anti-anchoring, reader-fit, and source-boundary guidance.
- Corrected examples and regression cases.
- A validated HTML revision-artifact builder and template.
- Plain-language rules for connected clauses, technical terms, and literal subjects.

## 1.0.0

- Published the first public skill, references, and GitHub Pages guide.
